# 背景音乐候选清单

现有：`assets/music/罐装毕加索 - Let Me Go(共创版).flac`（游戏会自动循环）。

放置方式：把音频文件（mp3 / ogg / wav / flac 都行）丢进 `assets/music/`，
游戏启动时自动挑一首循环；文件名带「大肥鱼 / let me go / fish」的优先，
其余按文件名排序取第一首。想换曲子，改名或只留一首即可。

风格目标：**深夜小店 + 霓虹 + 一点点怀旧**。公寓场景偏 lo-fi / 轻爵士；
科考站场景偏冷冽 ambient + 电子脉冲。下面都给了授权类型，商用/分发前按各自条款确认。

## C. 使用建议

1. **音量**：设置面板默认 0.2 就够，环境音别盖住提示音。
2. **切换**：以后做场景切换时，按场景换曲（公寓 lo-fi / 站内 ambient），用 `Music.apply()` 现成的接口。
3. **一段循环 1.5~3 分钟**最舒服；太短容易听出接缝。
4. 商用发布时：CC0 最省事；CC BY 记得在 README 或结局页写作者与链接；Pixabay 按它们的许可即可。
