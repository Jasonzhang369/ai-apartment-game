怎么开始玩
================================================

这是一个 Python + pygame 的桌面游戏，不是网页游戏。整个文件夹拷到哪都能跑。

1) 装 Python 3.10 或更高
   https://www.python.org/downloads/
   Windows 安装时务必勾选底部的 "Add Python to PATH"。

2) 装依赖（只有一个）
   pip install pygame

3) 启动
   macOS   ：双击「启动游戏.command」
             ⚠ 如果提示「无法打开，因为来自身份不明的开发者」：
               在文件上右键 → 选「打开」→ 再点「打开」，以后就能双击了。
   Windows ：双击「启动游戏.bat」
             它会自己找 Python、自己装 pygame。

4) 背景音乐（可选）
   把 mp3 / ogg / wav / flac / m4a 丢进 assets/music/ 就会自动循环播放。
   本仓库不自带音乐（版权原因），没有音乐也能正常玩，只是静音。
   音量在游戏里的「设置」面板调。

其他
------------------------------------------------
· 存档：save.json（和 game.py 同目录，自动保存）
· 设置：settings.json（音量 / 全屏，下次启动沿用）
· 出问题先看：启动日志.txt
· 详细玩法见 README.md
